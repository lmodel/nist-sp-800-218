# Datasets

* [nist-sp-800-218 LinkML schema](nist-sp-800-218-linkml-schema.md) - The LinkML schema of the Secure Software Development Framework (SSDF) version 1.1, `src/nist_sp_800_218/schema/nist_sp_800_218.yaml` (schema id `https://w3id.org/lmodel/nist-sp-800-218`, version 1.1.0): six classes, one enum of reference documents and four identifier types. Its `lokf adapt` copy `.lokf/nist-sp-800-218.yaml`, rooted on the practice group, the practice and the task, is the bundle's domain schema.
* [NIST's SSDF catalog copy](ssdf-catalog-copy.md) - NIST's catalog of SP 800-218 version 1.1 in the Open Security Controls Assessment Language (OSCAL), copied with NIST's licence from usnistgov/oscal-content v1.6.0 into `src/nist_sp_800_218/schema/oscal-content/` and matched to that release by git object hash. The tests derive the whole framework from it.
* [Generated artefacts](generated-artefacts.md) - What the LinkML generators and `lokf adapt` write from the schema: `project/` (JSON Schema, OWL, SHACL, ShEx, JSON-LD, GraphQL, protobuf, SQL, TypeScript, Excel and Java), the Python dataclasses and Pydantic models in `src/nist_sp_800_218/datamodel/`, `docs/schema/` and `docs/elements/`, and `.lokf/nist-sp-800-218.yaml`. None is edited by hand.
* [Test data and tests](test-data.md) - The schema's tests: seven valid examples and nineteen counter-examples under `tests/data/`, `tests/test_data.py`, which holds each to the validator, `tests/test_upstream.py`, which derives the framework from NIST's catalog, `tests/test_watch.py`, which runs the upstream watch against a stubbed upstream, and `tests/test_schema_rules.py`, which holds the adapt copy apart from LOKF and the slsa, github-actions and oscal copies in `tests/neighbours/`.
