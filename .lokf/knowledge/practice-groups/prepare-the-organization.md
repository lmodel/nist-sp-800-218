# Prepare the Organization (PO)

The catalog's overview of the group says that an organization should make sure its people, processes and technology are prepared to perform secure software development at the organization level. It adds that many organizations will find some PO practices useful for parts of their work too, such as single development groups or projects.[^nist_sp800-218_ver1_catalog.json] The group holds 5 practices and 13 tasks in SSDF version 1.1:

- `PO.1` Define Security Requirements for Software Development: 3 tasks
- `PO.2` Implement Roles and Responsibilities: 3 tasks
- `PO.3` Implement Supporting Toolchains: 3 tasks
- `PO.4` Define and Use Criteria for Software Security Checks: 2 tasks
- `PO.5` Implement and Maintain Secure Environments for Software Development: 2 tasks

The catalog marks task `PO.1.3` as formerly `PW.3.1`.
